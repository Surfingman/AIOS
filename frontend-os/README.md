# AIOS Desktop: Two Interfaces, One Backend

기존 Guardian 화면은 그대로 두고, 별도의 OS 스타일 인터페이스를 제공합니다.

## 실행

Python 3.14 (64-bit), Node.js 22.12 이상이 필요합니다. 이 폴더에서 실행하세요.

```powershell
.\run.ps1
```

기존 가상환경이 다른 PC나 Python 버전에서 생성됐으면 `-ResetVenv`를 사용합니다.
가상환경은 삭제하지 않고 백업한 뒤 다시 만듭니다. 설치와 빌드를 마친 후에는
`.\run.ps1 -SkipInstall -SkipBuild`로 시작할 수 있습니다.
실행 스크립트가 사용 가능한 포트와 주소를 출력합니다.

- OS: `http://127.0.0.1:8035/os/`
- 2D Canvas: `http://127.0.0.1:8035/workspace/`
- 기존 기본 화면: `http://127.0.0.1:8035/`

## 구성

- Three.js 얼굴 캐릭터: 대기, 듣기, 생각, 말하기 상태와 움직임 줄이기.
- 드래그 또는 좌우 버튼으로 회전하는 기능 링, 작업 표시줄, 이동/최대화/최소화 창.
- 일정, 회의, 이미지, 건강, 기억, 안전, 설정은 기존 Canvas를 같은 출처의 창으로 엽니다.
- 같은 탭의 세션 토큰과 `/api/workspace`를 공유합니다. 최소화한 Canvas 창의 입력도 유지합니다.
- 일정 변경, 이미지 생성, 동의, 보호자 정책은 기존 서버 검증을 그대로 통과해야 합니다.
- 웹 검색은 성인 프로필, `web_search` 허용, 도메인/안전 검사 후 명시적 승인으로 Bing을 엽니다.
- 선택한 1MB 이하 텍스트 파일은 브라우저에서만 읽습니다. 업로드나 디스크 전체 접근은 없습니다.
- 음성 입력은 별도 동의를 받으며 브라우저 음성 서비스로 전송될 수 있습니다. 입력 결과는 자동 실행하지 않습니다.

## 범위와 제한

브라우저 기반 OS 스타일 작업 공간이며 실제 Windows 셸이 아닙니다. 화면 가리기는
로그인/OS 잠금이 아니며, 화면 설정은 Windows 장치 설정을 변경하지 않습니다.
Canvas는 현재 반응형 카드 화면이며 새로운 생성형 레이아웃 엔진을 추가한 것은 아닙니다.
검색 결과 자체는 Guardian에서 필터링하지 않습니다. 미성년 프로필의 외부 검색은 차단합니다.
Azure AI는 루트 환경 설정과 기능별 전송 동의가 필요합니다. 미구성 시 로컬 제안이 동작합니다.
백엔드 재시작 또는 세션 만료 시 메모리 데이터는 사라집니다. 새 탭은 별도 세션일 수 있습니다.

## 개발

```powershell
npm ci
npm run dev
npm run build
```

Vite 개발 주소는 `http://127.0.0.1:5176/os/`이며 프록시 대상은 8035입니다.
백엔드를 다른 포트에서 실행하면 Vite 프록시도 맞춰야 합니다.
`../backend`와 `../frontend-canvas`가 필요하므로 배포할 때 이 폴더만 복사하지 마세요.

## 검증

서버 실행 후 이 폴더에서 테스트합니다. 브라우저 테스트는 설치된 Microsoft Edge를 사용합니다.

```powershell
npm run lint
npm run build
$env:AIOS_TEST_URL = 'http://127.0.0.1:8035'
npx playwright test --reporter=line
```

1440px/390px 화면의 캔버스 픽셀·애니메이션·기능 링·공유 세션·창 복원·파일 미리보기·음성 동의·채팅을 검사합니다.
스크린샷은 `test-results`에 생성됩니다. 실제 마이크, TTS 음성 출력 및 Azure 서비스 호출은 자동 테스트에 포함하지 않습니다.
